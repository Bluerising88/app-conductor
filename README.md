# Monitor Conductor (APK para Android)

App del conductor de **Monitor GPRS**. Es una herramienta interna para los choferes de las empresas que usan la gestión de viajes del portal: muestra los viajes asignados, deja marcar los eventos del viaje y envía la ubicación mientras el viaje está en curso.

Este repositorio solo publica el instalador (APK). No contiene código ni claves. La app no está en Google Play.

## Instalar

1. En el teléfono Android, abrir la sección **Releases** de este repositorio y descargar el archivo `app-conductor-<número>.apk` de la última versión.
2. Abrir el archivo descargado. La primera vez, Android pide permitir **instalar apps desconocidas** para el navegador (o la app con la que se abrió el archivo): activar el permiso y volver.
3. Tocar **Instalar** y abrir **Monitor Conductor**.
4. Ingresar con el usuario y la contraseña que entrega la empresa.

## Actualizaciones

No hace falta volver a esta página. Cuando hay una versión nueva, la app muestra el aviso **Nueva versión** en la lista de viajes. Al tocarlo, la descarga y abre el instalador de Android. La primera vez, Android pide permitir que **Monitor Conductor** instale apps.

Las versiones nuevas se instalan sobre la anterior y conservan la sesión y los datos del teléfono.

## Soporte

Ante cualquier problema, consultar con la empresa o con Monitor GPRS.
